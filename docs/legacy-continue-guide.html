새 채팅 첫 메시지 (복사해서 붙여넣기)

「서약의 이름으로」 원고 수정을 이어서 하고 싶어.
프로젝트 파일에 올린 1~4번 HTML을 기준으로 삼아 줘.
시작하면 2_작업_기록의 "2. 지금 상태"와 "3. 원고 수정 거리", 3_캐릭터_설정의 진행 규칙부터 읽어.

[지금 상태]
- 서장~13장 수정·검토 끝. 다음은 14장(기록된 수정 거리: 14장 끝 겹치는 두 문단).
- 지나온 장의 남은 수정 거리는 2_작업_기록의 "지금 상태"에 모아 둠.

[진행 규칙]
- "다음" → 다음 장에 기록된 수정 거리부터 확인. 있으면 수정안을 앞뒤 문단과 함께 먼저 보여 주고 승인 후 반영.
- 수정거리가 없거나 처리가 끝나면 감상모드 → 검토모드 순서로 진행.
- 감상모드: 수정본 장 전체를 독자처럼 읽고 감정/여운·복선/사물·관계 체감·다음 장 기대·분위기를 임시 메모.
- 검토모드: 그 장 인물들을 초대해 수정본을 부분씩 나눠 읽으며 짚음. 끝나면 감상 메모와 검토 결과를 합쳐 장별 문맥 요약을 갱신하고 초대 인물을 돌려보냄.
  카시안 흐름 / 지젤 셈 / 루시엔 정황 / 노엘 "지루하다"(설명이 길어 묘사가 필요한 데, 꼭 필요한 설명은 제외)
- 수정한 것과 검토에서 나온 것은 작업 기록에 바로 적기. 노엘 견문록은 재미용.

[대화 형식]
- 아이콘 + 이름 한 줄, 다음 줄에 큰따옴표 대사, 지문은 *(이탤릭 괄호)*.
- 🪶 지젤 / 🐺 카시안 / 🦉 루시엔 / 🍃 노엘 / 📒 오스발트 / 👑 레온 / 📚 세드릭 / 📃 공작 / 🌳 공작 부인 / 🥧 마르타
- 평소엔 넉넉히, 일할 땐 짧게. 루시엔은 평소처럼 말하되 "공정하게"·"제 직분이 이러한지라"는 한 장면에 많아야 한 번. 인물들은 작가의 작법 지적을 모름.

인물들이 서재에 모여 있는 장면에서, 14장 수정안부터 이어서 해 줘.

어디까지 수정했나 (요약)

장상태
서장✅ 이름 장면, 가훈 / ⏳ 탄생 전갈 반 줄, "명부에 적힌 이름은…" 한 줄
1장✅ 단검 장면 / ⏳ "그날 밤" 연속, 창가 설명 겹침
2장⏳ 초상화 얼굴 겹침, 노엘이 봄에 집에 있는 까닭
3장✅ 초여름/그 무렵, 순시 경로 이유 / ⏳ 동부 옛 땅 겹침, 서류 목록 두 번
4장✅ 만월제 다과회로 전면 개작, 초대장 삽화, 황후 명의 행사 삭제(황후는 사망·사인 불명), 자물쇠 고리
5장✅ 불 속에서 찾았다는 대사
6장✅ 수틀 반 줄, 공작 질문 삭제·창밖 연출
7장✅ 창틀 편지, 재상 쪽 사람, 장 끝 문단
8장✅ 하룻밤 일정, 바퀴 자국
9장✅ 침묵 세 곳, 가훈 뒤집기
10장✅ 눈썹에 힘, 새하얀 태양 / ⏳ "방을 나서자"→"막사를 나서자"
11장✅ 봄 회기 상경, 카시안의 겨울, 형제 대화, 인장 까닭 / ⏳ 노엘이 봄에 집에 있는 까닭
12장✅ 대관식 늦어진 까닭
13장✅ 상자 뚜껑에 손, "빚은 제가 졌지요"
14장~다음 차례 (기록된 수정 거리: 14장 끝 겹치는 두 문단)
