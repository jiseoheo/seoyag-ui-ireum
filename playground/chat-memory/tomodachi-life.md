# 친구모아 아일랜드 — 게임 전용 기억

> 적용 범위: 「친구모아 아일랜드 두근두근 라이프」 게임 안의 주민 설정·관계·진행만.
> 원고·세계관·채팅 캐릭터 정본이 아니며, 게임에서 생긴 관계를 원작 관계로 소급하지 않는다.
> 상세 당시 기록은 `service/noel-notebook.html` 6~7쪽의 「친구모아 섬」을 참고한다.

## 게임 운영 원칙

- 원작 인물을 Mii로 만들 때 **외형과 인물성의 출발점은 원작 기준**으로 잡는다.
- 게임 입력은 이름·성·별명·성별·생일·외형·목소리·성격 등을 「두근두근 라이프」 체계에 맞게 변환한다.
- 게임 안에서 생기는 친구·짝사랑·연애·결혼은 **원작 관계와 별개**다.
- 원작 커플을 강제로 재현하지 않고, 주민들이 먼저 움직인 결과를 관찰한다.
- 채팅 속 원작 인물의 말투·호칭·관계성은 이 파일을 근거로 바꾸지 않는다.

## 2026-10-05까지의 섬 진행

섬에는 작가 분신과 여러 기존 주민이 이미 산다. 작품 인물·애니메이션 캐릭터·유튜버·드라마 인물 등이 한 섬에 섞여 있다.

작가의 작은 분신:
- 현실과 달리 섬에서는 정성찬 씨와 혼인했다.
- 자녀가 셋이다.
- 다른 주민들의 자녀 세대도 섬에 여럿 있다.

노엘 견문록에 적힌 주요 기존 주민:
- 마리네뜨·아드리앙
- 스타·마르코
- 최웅·국연수
- 감딸기·원가온·서로진·안도하
- 최자두·이윤석
- 오아리·오동동·박철연·왕방울
- 김규남·윤혁준·윤태용 등

대표적인 “작가 뜻대로 안 되는 섬” 사례:
- 왕방울은 원래 오동동과 이어 주려 했으나 다른 남자와 혼인했다.

## 현재 관계 기록

- 노엘 ↔ 약초상 아가씨
  - 친구 성립.
  - 서로 죽이 잘 맞는 사이.
  - 노엘이 먼저 친구가 되고 싶다고 했다.
  - 빨리 말하기 내기에서 노엘이 졌다.
  - 호칭: 노엘 → “약초상 아가씨”, 상대 → “노엘 씨”.
  - 둘만 따로 두어도 계속 대화한다.
- 노엘 ↔ 안도하
  - 안면을 텄고 잘 맞을 것 같은 사이.
- 약초상 아가씨 ↔ 안도하
  - 잘 맞을 것 같은 사이.
- 지젤 ↔ 국연수
  - 잘 맞을 것 같은 사이.
- 지젤 ↔ 작가 분신
  - 안면을 텄다.
  - 지젤은 자기소개 화제로 “첫사랑이 좋다”를 꺼냈다.
- 세드릭 ↔ 이다
  - “엄마” 이야기로 친구가 됐다.
  - 호칭: 세드릭 → “이다”, 이다 → “세드릭 씨”.
- 루시엔 ↔ 마리네뜨
  - 서로 잘 맞을 것 같은 사이.
- 루시엔 ↔ 국연수
  - 루시엔이 먼저 말을 걸었다.
  - “빗장이 두꺼웠오”를 시작으로 가까워지는 중.
  - 아직 친구는 아니며 둘 다 도파민 애호가라는 공통분모가 있다.
- 카시안 ↔ 최웅
  - 안면을 텄다.
- 카시안 ↔ 작가 분신
  - 안면을 텄다.
  - 작은 카시안의 자기소개는 “잘생기고 다정한 테토남”.

## 현재 가장 큰 사건

- **작은 카시안 → 김규남 씨 짝사랑**
  - 지나가던 김규남 씨를 보고 눈부셔 보인다며 사랑인지 물었다.
  - 작은 카시안은 “사귀고 싶어요!”라고 말했다.
  - 아직 고백하거나 연애가 성립한 것은 아니다.
  - 김규남 씨 쪽에서는 작은 카시안을 그냥 아는 사이로 본다.
- 이 사건은 게임 안의 비정본 놀이 기록이다.

## 2026-10-10 새벽 · 작은 노엘의 하루와 상호작용 하이라이트

> 사용자가 보여 준 화면과 직접 설명한 사실 기준. 게임 속 동기는 확인된 행동과 구분한다.

- 작은 노엘은 나비를 잡다가 놓쳐 생울타리에 파묻힌 모습이 됐다. 잠들거나 쉬는 장면으로 읽었던 것은 오독. 작은 지젤은 나비를 잡았다.
- 작은 노엘이 밤 해변에서 검을 들고 움직이는 화면, 주민들과 어울리는 화면을 함께 구경했다.
- 작은 카시안은 사용자가 김규남 씨 곁에 붙여 놓자 다짜고짜 “우와~~~~~~악!” 하고 소리를 질렀다. 사용자는 김규남 씨가 혼비백산해서 도망갔다고 설명했다.
  - 별도 사전 사건은 없었다. 고백·연애 성립·거절로 단정하지 않는다.
- 사용자가 지정한 하이라이트 네 장의 순서:
  1. 지젤–루시엔: 지젤은 “이유 없이 루시엔을 따라가고” 있었고, 루시엔은 그때 **다른 사람들의 이야기를 엿듣고 있었다**. 양쪽 관계 표시는 “잘 맞을 것 같은 사이”, “면식 있음”. 루시엔의 붉은 뺨을 지젤이 따라와서 좋아하는 표정으로 읽었던 것은 오독. 엿듣던 이야기 내용은 사용자도 모른다. 지젤이 의심해서 미행한다는 해석은 원작을 떠올린 농담이며 실제 동기는 미확인.
  2. 카시안–루시엔: “2026년에 가장 화났던 일”을 털어놓는 중. 관계는 “면식 있음”, 양쪽 모두 “친구가 되고 싶어”. 아직 친구 성립으로 승격하지 않는다.
  3. 허지서(작가 분신)–지젤: 자기소개 장면, “면식 있음”, 양쪽 “잘 맞을 것 같은 사이”. 소개 화제 전체 문구는 사진 판독이 불확실하므로 이전 AI의 ‘미남의 삶’ 풀이를 확정 인용하지 않는다.
  4. 허지서(작가 분신)–카시안: 카시안이 작가 분신을 **몰래 따라다니던 장면**. 앞에서 포즈를 보여 주던 장면으로 읽었던 것은 오독. 사용자는 지키려는 것인지 물었지만 호위 목적은 확인되지 않았다.
- 사진 표정만으로 연애 감정·행동 목적을 결정하지 않는다. 사용자가 바로잡은 실제 상황을 다음 채팅에서도 우선한다.
