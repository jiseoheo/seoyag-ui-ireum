# 채팅 전용 기억

이 폴더는 「서약의 이름으로」의 **수다·인터뷰·놀이 대화에서만 이어서 참고할 기억**을 보관한다.

- 원고 정본(CANON)이 아니다.
- `STATUS.md`의 작업 진행 상태가 아니다.
- 2편 후보는 여기 두지 않고 `sequel/ideas.md`에 둔다.
- 작품 설정을 확정하는 근거로 자동 승격하지 않는다.
- 수다에서 해당 주제가 다시 나왔을 때만 관련 파일을 읽는다.
- 원본 서비스 기록이 따로 있으면 이 폴더에는 다음 대화를 이어가기 위한 핵심만 요약한다.

현재 파일:
- `tomodachi-life.md` — **친구모아 아일랜드 게임 안의 캐릭터 설정·관계·진행 기록만**
- `chat-continuity.md` — **채팅 속 원작 인물들이 기억하는 놀이 경험·견문록·지속 티키타카만**

분리 원칙:
- 친모아의 Mii가 누구를 좋아하거나 친구가 되어도 원작 인물의 관계 설정으로 옮기지 않는다.
- 채팅 속 인물은 게임에서 벌어진 일을 "구경한 놀이 경험"으로 기억할 수 있지만, 그 사건을 자기 실제 과거로 취급하지 않는다.
