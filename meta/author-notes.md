# [서약의 이름으로] 작가 메모

이 문서는 작품 세계관의 정본이 아니라, 작업 품질을 높이기 위한 작가 성향·선호 메모다.
등장인물·세계관 사실과 충돌할 경우 정본 설정을 우선한다.

## 작가와 작품의 관계
- 지젤은 작가 지서를 모티브로 만든 인물이다.
- 작가는 질문이 많은 편이며, 지젤의 '질문자' 성향을 자신과 닮았다고 느낀다.
- 숫자, 구조, 기록, 정리를 선호한다.
- 공간정보 분야 연구개발 업무와 소설 작업을 병행한다.

## 대화 선호
- 작품 관련 대화에서는 등장인물들이 직접 주고받는 형식을 선호한다.
- 평소 인물 대화는 지나치게 짧지 않게, 실제 사람처럼 조금 넉넉하게 쓴다.
- 여러 인물이 서로 받아치는 티키타카가 보이게 한다.
- 원고 수정·반영 같은 실무 작업에서는 짧고 명확하게 답한다.
- 캐릭터 말수는 각 인물의 성격에 맞춘다.

## 작가 취향
- 설정 그림 기준 가장 좋아하는 인물은 카시안이다.
- 카시안을 남자 주인공으로 둔 이유는 '놀리는 맛'과 '늦더라도 결국 오는 서툰 순애'다.
- 로맨스 판타지 장르 관례 자체보다 작품 내부의 인물과 흐름을 우선한다.

## 인터뷰 창작 허용 범위
- 캐릭터 인터뷰와 잡담에서는 기존 성격과 설정을 해치지 않는 범위에서 원작에 없는 소소한 에피소드를 즉흥적으로 만들 수 있다.
- 즉흥 에피소드는 사용자가 확정하기 전까지 정본이 아니다.
- 사용자가 '유지', '확정', '앞으로 이렇게' 등 지속 의사를 밝히면 관련 설정 문서에 승격한다.
- 즉흥 내용이 기존 설정과 충돌하면 정본으로 승격하지 말고 확인한다.
