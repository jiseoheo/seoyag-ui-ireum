# 22장 검토

> 장별 검토 작업 메모. 해당 장 작업을 할 때만 읽는다. 장 완료 처리 때 이 파일을 지운다(이력은 Git history).

## 승인 결과
- "그의 짐은" → "루시엔의 짐은"
- "비로소 가면을 벗은 사람 같았다." 삭제
- "수평선 너머의 점" → "수평선 위의 점"
- "그녀의 젖은 어깨에" → "바람에 언 어깨에"

## 보류 후보
- 손등 입맞춤 직전("그는 그녀의 손을 들어 올려, 처음으로 그 손등에 입을 맞추었다."), 커프스가 없는 소매를 짧게 보여 주는 안. 갈색 외투가 이미 같은 뜻을 전한다는 반론 있음. 넣기로 하면 문장안부터 작성.
