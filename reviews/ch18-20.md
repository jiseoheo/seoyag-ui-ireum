# 18~20장 미반영 검토 메모

> 장별 검토 작업 메모. 해당 장 작업을 할 때만 읽는다. 장 완료 처리 때 이 파일을 지운다(이력은 Git history).

- 18장: "둘을 한꺼번에 품고도 셈이 맞는 일은 장부 속에 없었다" 삭제 후보. 기존에는 지젤의 인식 단계보다 앞서 보일 수 있다는 검토였으나, 2026-10-05 전체 문맥 검토에서 「셈」 비유의 반복을 줄이는 이유를 중심으로 재검토하기로 함. 16장의 대표 대사와 18장 제목·앞의 숫자 묘사가 있으므로 이 문장까지 감정을 해설할 필요가 적다. 동일 문장을 별도 후보로 중복 등록하지 않는다.
- 19장: "내일이면 떠날 사람이었다. 돌아온다는 약속조차 할 수 없는 곳으로." 설명 겹침 가능성.
- 19장: "너무 오래 쓰지 않은 근육이 삐걱이는 것 같은 서툰 웃음"이 다소 길 수 있음.
- 20장: "남쪽행 배를 놓친 뒤로"는 실제로는 스스로 타지 않은 것이므로 "타지 않은 뒤로"가 더 정확함.
- 20장: "그의 목소리 어디에도 원망은 없었다." / "우는 법을 오래 잊고 살아온 사람의 서툰 울음이었다."는 행동이 이미 보여 준 내용을 해설하는 문장이라 삭제 후보.

위 메모는 사용자가 따로 돌아가자고 하지 않는 한 현재 21장 검토를 막지 않는다.

## 추후 수정사항 — 「셈」 표현 반복 줄이기 (2026-10-05)
- 사용자가 반복을 줄이는 방향을 채택하고 수정사항 등록을 요청함. 원고 및 최종 문구는 아직 미반영·미승인.
- 18장: "이번 셈은 오래 걸리지 않았다." 변경 후보. 앞의 "마지막으로 아무 걱정 없이 잠든 밤이 언제였더라."에서 구체적인 기억으로 바로 이어지게 한다. 예시 후보: "그 밤은 곧 떠올랐다." 최종 문구는 승인 전이다.
- 20장: "적으면 정말 셈이 될 것 같았다." 삭제 후보. "장부에 적듯 적어 두지는 않았다."와 날짜를 세는 행동은 보존하고, 그 행동을 다시 해설하는 문장을 덜어낸다.
- 공통 기준: 실제 일을 하는 셈과 대표 대사는 살리고, 감정을 해설하는 반복부터 줄인다. 「셈」을 「계산」 등 동의어로 일괄 치환하지 않는다. 서장의 공작, 11장의 빈 장부, 백합을 세는 행동은 유지 방향이다.
