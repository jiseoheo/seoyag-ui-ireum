# 18~20장 미반영 검토 메모

> 장별 검토 작업 메모. 해당 장 작업을 할 때만 읽는다. 장 완료 처리 때 이 파일을 지운다(이력은 Git history).

- 18장: "둘을 한꺼번에 품고도 셈이 맞는 일은 장부 속에 없었다"가 현재 지젤의 인식 단계보다 조금 앞서 보일 수 있음.
- 19장: "내일이면 떠날 사람이었다. 돌아온다는 약속조차 할 수 없는 곳으로." 설명 겹침 가능성.
- 19장: "너무 오래 쓰지 않은 근육이 삐걱이는 것 같은 서툰 웃음"이 다소 길 수 있음.
- 20장: "남쪽행 배를 놓친 뒤로"는 실제로는 스스로 타지 않은 것이므로 "타지 않은 뒤로"가 더 정확함.
- 20장: "그의 목소리 어디에도 원망은 없었다." / "우는 법을 오래 잊고 살아온 사람의 서툰 울음이었다."는 행동이 이미 보여 준 내용을 해설하는 문장이라 삭제 후보.

위 메모는 사용자가 따로 돌아가자고 하지 않는 한 현재 21장 검토를 막지 않는다.
