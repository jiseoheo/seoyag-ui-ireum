# 노엘의 견문록 이미지 보관함

`service/noel-notebook.html`에서 사용하는 사진·이미지 자산을 보관한다.

- 이미지 파일은 HTML에 직접 데이터로 삽입하지 않는다.
- 이 폴더에 파일로 저장한 뒤 `noel-notebook.html`에서 상대경로로 링크한다.
- 예: `noel-notebook-assets/파일명.png`
- 견문록에 사진을 추가할 때는 기존 19세기풍 기록장 디자인과 어울리게 배치한다.
- 사진은 **다꾸하듯 아주 작게** 넣는다. 큰 자료사진·전면 사진은 쓰지 않고, 여백이나 문단 사이에 붙인 작은 인화사진·스크랩 조각·스티커처럼 사용한다.
- 사진이 본문보다 시선을 더 끌거나 글을 가리면 안 된다.
- 사진 추가는 채팅 기준 서비스 확장이며 원고 정본 사건을 새로 확정하지 않는다.
