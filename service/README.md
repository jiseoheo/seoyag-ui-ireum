## 노엘의 견문록 확정 기준
- `service/noel-notebook.html`은 **채팅 기준 서비스**다. 원고 정본 사건을 새로 확정하는 문서가 아니다.
- 사용자가 최종 승인한 방향:
  - 시대·작중 문서 양식을 고려한 **19세기풍 개인 견문/야전 기록장** 디자인.
  - 인물별 실제 한글 손글씨 폰트를 사용해 필체를 구분.
  - 노엘은 24살 성인에 맞는 자연스럽고 빠른 필기체.
  - 최종 승인 뒤 전체 글씨 크기를 한 단계 줄인 버전을 기준으로 한다.
- 인물별 서비스 필체 기준(2026-10-05, 원고 삽화 손글씨에 맞춰 변경):
  - 지젤 = Hi Melody
  - 카시안 = East Sea Dokdo
  - 루시엔 = Nanum Pen Script
  - 노엘 = Nanum Pen Script
  - 오스발트 = UnGungseo
- 노엘과 루시엔은 같은 글꼴이다. 크기·색·기울기로 구분할지는 작가 확인 대기.
- 사용자가 서비스/HTML 결과물을 "보여줘"라고 하면 설명이나 코드 발췌가 아니라 **실행 가능한 결과물**을 우선 보여 준다.
- 노엘은 잡담·감상·인터뷰 중 연구할 만한 말/관찰을 스스로 견문록에 추가할 수 있다. 새로 적은 내용은 작가에게 바로 보여 준다.
- 카시안 → 노엘 말투는 맥락 구분:
  - 업무·훈련·기사단 관계 = 해라체.
  - 가족으로 만나는 자리 = 존대.
- 관련 최근 커밋:
  - `225c9e313b742c0e8519a8452e27325bdaffa089` 카시안→노엘 업무/가족 말투 구분.
  - `d2147a2b95b3d0f920204b09a0e784d940455f12` 노엘 견문록 최종 디자인/글씨 크기 기준 반영.
- 이 서비스 디자인은 사용자가 "좋아 이거로 가자"라고 승인했다. 별도 요청이 없으면 다시 디자인 후보를 제안하지 않는다.
