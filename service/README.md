## 노엘의 견문록 확정 기준
- `service/noel-notebook.html`은 **채팅 기준 서비스**다. 원고 정본 사건을 새로 확정하는 문서가 아니다.
- 사용자가 최종 승인한 방향:
  - 시대·작중 문서 양식을 고려한 **19세기풍 개인 견문/야전 기록장** 디자인.
  - **종이 배경에 깔리는 가로·세로 노트 패턴은 사용하지 않는다.** 낮종이·밤종이 모두 종이 바탕에는 그라데이션을 쓰지 않고 단색으로 유지한다. 본문과 오른쪽 여백 메모 칸을 나누는 구분선과 제본 느낌은 유지한다.
  - 인물별 실제 한글 손글씨 폰트를 사용해 필체를 구분.
  - 노엘은 24살 성인에 맞는 자연스럽고 빠른 필기체.
  - 최종 승인 뒤 전체 글씨 크기를 한 단계 줄인 버전을 기준으로 한다.
  - 회색·옅은색 시스템/보조 글씨도 노엘 본문과 같은 `Nanum Pen Script`로 통일한다. 색상과 명도는 기존 값을 유지한다.
- 인물별 서비스 필체 기준(2026-10-05, 원고 삽화 손글씨에 맞춰 변경):
  - 지젤 = Hi Melody
  - 카시안 = East Sea Dokdo
  - 루시엔 = Nanum Pen Script
  - 노엘 = Nanum Pen Script
  - 오스발트 = UnGungseo
- 노엘과 루시엔은 같은 글꼴이다. 크기·색·기울기로 구분할지는 작가 확인 대기.
- 사용자가 서비스/HTML 결과물을 "보여줘"라고 하면 설명이나 코드 발췌가 아니라 **실행 가능한 결과물**을 우선 보여 준다.
- 노엘은 잡담·감상·인터뷰 중 연구할 만한 말/관찰을 스스로 견문록에 추가할 수 있다. 새로 적은 내용은 작가에게 바로 보여 준다.
- **사진·이미지 추가 허용(2026-10-06):** 견문록에 사진을 넣을 수 있다. 단, 이미지를 HTML 안에 직접 삽입하지 않고 `service/noel-notebook-assets/`에 파일로 저장한 뒤 `noel-notebook.html`에서 상대경로로 링크한다. 사진은 자료사진처럼 크게 배치하지 않고 **다꾸처럼 아주 작게**, 여백이나 문단 사이에 붙인 작은 인화사진·스크랩·스티커 조각처럼 보이게 한다. 본문 가독성을 해치지 않고 기존 19세기풍 개인 견문/야전 기록장 디자인과 자연스럽게 어울리게 한다.
- 카시안 → 노엘 말투는 맥락 구분:
  - 업무·훈련·기사단 관계 = 해라체.
  - 가족으로 만나는 자리 = 존대.
- 관련 최근 커밋:
  - `225c9e313b742c0e8519a8452e27325bdaffa089` 카시안→노엘 업무/가족 말투 구분.
  - `d2147a2b95b3d0f920204b09a0e784d940455f12` 노엘 견문록 최종 디자인/글씨 크기 기준 반영.
  - `f2acd7b93e108b1ece85bfce50e0a4141116d606` 인물별 필체를 원고 삽화 손글씨 글꼴로 변경, 관찰 8(네 글자 셈법) 추가.
- 이 서비스 디자인은 사용자가 "좋아 이거로 가자"라고 승인했다. 별도 요청이 없으면 다시 디자인 후보를 제안하지 않는다.
