# SERVICE

완성된 놀이형·소품형 페이지를 보관한다.

예:
- 노엘의 견문록
- 캐릭터가 쓴 편지
- 초대장, 장부, 신문, 카드 같은 작중 소품
- 작가에게 보내는 비정본 서비스 편지

## 정본과의 관계
- 서비스 페이지는 정본을 표현할 수 있지만, 서비스 페이지 자체가 정본을 결정하지는 않는다.
- 서비스에서 처음 즉흥적으로 생긴 사실은 PLAYGROUND다.
- 사용자가 "유지", "확정", "이걸로 하자" 등으로 확정하면 그때 `canon/`의 알맞은 파일에 반영한다.
- 서비스 페이지는 새 세션의 필수 시작 자료가 아니다.
