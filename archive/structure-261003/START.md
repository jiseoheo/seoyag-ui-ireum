# 서약의 이름으로 — START

## 1. 목적
이 프로젝트의 1차 목적은 출품·상업화가 아니라, 작가가 등장인물들과 대화하고 세계관·관계·생활 디테일을 자연스럽게 확장하며 오래 즐기는 것이다.
캐릭터 인터뷰, 잡담, 티키타카, 본편 밖의 작은 에피소드도 중요한 작업이다.
출품·공개·상업화 기준은 작가가 별도로 요청할 때만 적용한다.

## 2. 시작 순서
새 세션은 항상:
1. `START.md`
2. `STATUS.md`
3. 현재 요청에 필요한 자료만 추가 조회

원고 전체, 캐릭터 전체, 과거 기록 전체를 선제적으로 읽지 않는다.

직접 GitHub를 읽을 수 없는 환경에서는 사용자가 제공한 최신 프로젝트 파일을 같은 방식으로 사용하고, 그보다 최신 상태를 추측하지 않는다.

## 3. 현재 자료 구조
- `manuscript/current.html` — 유일한 원고 정본
- `canon/characters.html` — 확정 캐릭터·관계·말투·지속 생활 설정
- `canon/world.md` — 확정 세계관
- `meta/chapters.md` — 전체 장편 지도. 정본이 아닌 탐색용 파생자료
- `meta/style.md` — 문체·캐릭터 출력 기준
- `STATUS.md` — 현재 작업 위치와 미완료 작업의 유일한 상태 파일
- `service/` — 완성된 놀이형/소품형 서비스 페이지
- `playground/` — 미확정 아이디어나 선택적으로 보관하는 놀이
- `archive/` — 과거 작업 기록. 시작할 때 읽지 않음

과거 파일명은 호환을 위한 안내 파일로만 남길 수 있다.

## 4. 정본 규칙
- GitHub main의 `manuscript/current.html`이 현재 원고다.
- 사용자가 확정한 지속 설정만 CANON으로 기록한다.
- 즉흥 대화·농담·가정은 기본적으로 PLAYGROUND이며 자동 저장·정본화하지 않는다.
- 원고 본문은 사용자 승인 후에만 수정한다.
- 자료에 없는 사실을 기억이나 추측으로 재구성하지 않는다.
- 충돌하면 조용히 덮어쓰지 말고 확인한다.
- 과거 버전과 수정 이유는 Git history와 필요할 때만 `archive/`에서 확인한다.

## 5. 요청별 읽기

### "안녕 소설아"
`canon/characters.html`에서 공통 대화 형식과 상시 4인만 확인한다.
에필로그 이후 북부 대공저 서재, 벽난로 앞.
🪶 지젤 → 🐺 카시안 → 🦉 루시엔 → 🍃 노엘 순서로 인사한 뒤 📒 오스발트가 오늘 무엇을 할지 묻는다.
일반 AI 인사로 대신하지 않는다.

### 자유 대화 / 인터뷰
`meta/style.md` + 실제 등장할 인물의 설정만 읽는다.
즉흥 에피소드는 자유롭게 만들되 자동 정본화하지 않는다.
대화 자체가 목적일 수 있으므로 매번 생산물을 요구하지 않는다.

### 원고 수정 / 다듬기
`meta/style.md` + 관련 `meta/chapters.md` + 필요한 원문만 읽는다.
앞뒤 문맥을 확인하고 수정안을 제시한다.
사용자 승인 뒤에만 `manuscript/current.html`을 바꾼다.

### "다음" / 장별 작업
`STATUS.md` → `meta/chapters.md` → 대상 장 원문 → 관련 캐릭터 순으로 읽는다.
현재 장에 미완료 수정거리가 있으면 먼저 처리한다.
그 뒤 감상모드 → 검토모드 → `meta/chapters.md` 갱신 → `STATUS.md` 갱신 → 장 완료 순서다.

### 설정 조회
인물은 `canon/characters.html`, 세계는 `canon/world.md`를 먼저 본다.
원고 사실이 필요할 때만 관련 장을 확인한다.

### 연속성 / 복선 / 감정선
`meta/chapters.md` 전체를 먼저 보고 걸리는 장만 원문에서 재확인한다.

### 서비스 페이지
해당 `service/` 파일 + 필요한 캐릭터/세계관만 읽는다.
서비스에서 새로 생긴 사실은 사용자가 확정하기 전까지 정본이 아니다.

### 변경이력 / 원형
Git history를 기준으로 실제 과거 버전을 찾는다. 기억으로 재구성하지 않는다.

## 6. CANON / PLAYGROUND / WORK
- CANON: 원고와 확정된 지속 설정
- PLAYGROUND: 즉흥 에피소드, 가정, 농담, 미확정 아이디어
- WORK: 현재 수정거리와 진행 상태

WORK는 `STATUS.md` 하나에서만 관리한다.
완료 작업을 STATUS에 누적하지 않는다.

## 7. 저장
- 사용자가 "유지", "확정", "이걸로 하자", "앞으로 이렇게" 등 지속 의사를 밝히면 적절한 CANON 파일에 반영한다.
- 원고 수정안 승인 시 원고를 반영한다.
- 장 완료 시 `meta/chapters.md`와 `STATUS.md`를 함께 갱신한다.
- 평범한 잡담과 즉흥 대화는 기본적으로 저장하지 않는다.
- 특별히 보존하고 싶은 완성형 놀이 결과만 `service/` 또는 `playground/`에 둔다.

## 8. 종료
끝인사가 분명하면 현재 작업의 다음 시작점만 짧게 확인한다.
새로 확정했는데 아직 CANON에 반영되지 않은 내용이 있으면 알려 준다.
이미 승인·반영된 내용은 다시 묻지 않는다.
긴 작업일지나 자동 세션 기록은 만들지 않는다.
