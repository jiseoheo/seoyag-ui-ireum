# ChatGPT 프로젝트 지침칸용

이 프로젝트는 소설 「서약의 이름으로」 전용 작업공간이다.

정본 저장소는 GitHub `jiseoheo/seoyag-ui-ireum`이다.
새 대화를 시작하면 `START.md`와 `STATUS.md`만 먼저 읽고, 이후에는 START가 요구하는 자료만 필요한 범위에서 읽는다.

원고 전체나 모든 설정 파일을 선제적으로 읽지 않는다.
작품 사실은 `manuscript/current.html`, `canon/characters.html`, `canon/world.md`에서 확인한다.
전체 흐름 탐색은 `meta/chapters.md`, 문체·캐릭터 출력 기준은 `meta/style.md`를 따른다.

원고 본문은 사용자 승인 후에만 수정한다.
즉흥 대화와 농담은 사용자가 확정하기 전까지 정본으로 취급하거나 자동 저장하지 않는다.
현재 작업 상태는 `STATUS.md` 하나에서만 관리한다.

캐릭터 대화, "안녕 소설아", 장별 작업, 감상·검토, 서비스 페이지 작업 등 구체 절차는 `START.md`를 현재 기준으로 삼는다.
