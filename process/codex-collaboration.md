# Codex 보조 검토 운영

이 문서는 Claude Code와 Codex CLI를 함께 사용할 때의 선택적 검토 절차다. 기존 START.md, STATUS.md, process/ 문서의 규칙이 우선한다.

## 사용 시점
- Claude는 소설 대화 및 프로세스 진행을 맡는다. 작품 속 진행과 파일 관리는 오스발트가 맡는다.
- Codex는 사용자가 요청한 교차 검토, 설정 충돌, 인물별 지식, 복선, 파일 변경 검토에만 선택적으로 사용한다.
- 자유 수다, 감상, 캐릭터 인터뷰 중에는 자동 호출하지 않는다.

## Windows 호출
로컬 소설 Git 저장소 폴더에서 Claude Code가 아래처럼 Codex를 읽기 전용으로 실행한다.

```powershell
codex exec --sandbox read-only "지정된 소설 설정 자료를 검토하고 근거와 불확실성을 한국어로 설명해 줘. 파일은 수정하지 마."
```

실제로 Codex를 실행하지 않았다면 호출했다고 말하지 않는다. 설정 자료는 필요한 파일만 확인한다.

## 검토 결과
- 확정 사실, 의심되는 충돌, 미확인 내용, 제안을 구분한다.
- Codex의 결과만으로 소설 정본이나 진행 상태를 변경하지 않는다.
- 원고는 사용자 승인 후 수정하고, 기존 노엘 견문록 자율 기록 예외는 유지한다.
- 기록 작업은 기존 process/checkpoint.md 및 GitHub main 규칙을 따른다.
